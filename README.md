# THE FORGOTTEN FOREST — 잊혀진 숲

Three.js와 Vite로 만든 PC 브라우저용 1인칭 공포 탈출 게임입니다. 서버, DB, API 키 없이 정적 호스팅에서 작동합니다. 잔혹한 장면 없이 안개, 소리와 추격으로 긴장감을 만듭니다.

## 실행

Node.js 20.19+ 또는 22.12+ 권장.

```sh
npm install
npm run dev
```

표시되는 로컬 주소(기본 `http://localhost:5173`)를 PC 브라우저에서 엽니다. WebGL 하드웨어 가속을 권장합니다. NEW GAME 또는 계속하기를 직접 클릭해야 마우스 잠금과 오디오가 시작됩니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`가 배포 결과물입니다. 파일을 직접 더블 클릭하는 `file://` 실행은 지원하지 않습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / Mouse | 이동 / 시야 |
| Shift | 달리기 (기력 소모) |
| Ctrl | 웅크리기 (느린 이동, 감지 거리 감소) |
| E | 바라보는 근처 물체 조사 / 수집 / 문 열기 |
| F | 손전등 |
| Tab | 인벤토리 / 기록 다시 읽기 / 사진 조합 |
| Esc | 일시정지 / 마우스 해제 |

패널을 닫으면 일시정지 화면으로 돌아갑니다. ‘계속하기’를 누르면 마우스가 다시 잠깁니다. 포커스를 잃거나 마우스 잠금이 풀려도 일시정지합니다.

## 구현

- 실시간 메뉴 배경, 메뉴 전환과 호버 효과, 한국어 안내
- 절차적 지형, 인스턴스 나무/풀, 바위, 오두막, 폐기록관, 동굴과 출구
- FPS 카메라, 지형 높이 보정, 벽/나무/바위 충돌과 벽을 따라 미끄러지는 이동
- 손전등 SpotLight, 달빛, 실시간 그림자, 거리 안개, 먼지, 톤 매핑
- 다섯 챕터, 편지/사진/열쇠/기록/퓨즈 수집, 사진 순서 퍼즐과 날짜 암호, 전기 스위치와 잠긴 철문
- PATROL / INVESTIGATE / CHASE / SEARCH / RETURN 적 상태 머신. 시야각, 거리, 2D 장애물 시선 검사, 발소리 감지, A* 경로와 충돌 이동
- 게임 오버와 체크포인트 재시작, 단서 수집에 따른 두 엔딩
- Web Audio 합성 바람, 저음 환경음, 발소리, 스위치, 문, 추격 박동, 퍼즐 효과음
- localStorage 체크포인트, 아이템, 퍼즐, 설정 저장; 저장이 없으면 CONTINUE 비활성화
- Low / Medium / High 렌더 거리와 픽셀 비율, 해상도 스케일, 그림자, 감도, 흔들림, FPS, 음악/효과음 설정

## 챕터와 공략 (스포일러)

1. 시작 지점 앞의 손전등과 편지를 E로 수집합니다. 처음 바라보는 방향이 북쪽입니다. 길을 따라 오두막으로 갑니다.
2. 오두막 안 2개와 주변 2개의 사진 조각을 찾습니다. 관리인의 일지와 황동 열쇠도 챙깁니다. Tab → 사진 조합에서 **III, I, IV, II** 순으로 선택합니다. 북쪽 철문 앞에서 E를 눌러 엽니다.
3. 북쪽 기록관으로 갑니다. 적이 보이면 기력을 남겨 달리고, 나무와 바위로 시야를 끊고 Ctrl로 몸을 낮춥니다. 기록관에 도착하면 추격이 멈춥니다.
4. 기록관 안 사건 기록을 읽습니다. 왼쪽 전력 스위치를 켜고 오른쪽 보관함에 **0814**를 입력해 퓨즈를 얻습니다. 두 번째 엔딩을 원하면 기록관 오른쪽 뒤의 ‘이름이 지워진 편지’도 읽습니다. 북쪽 비상 철문을 E로 엽니다.
5. 추격을 피해 동굴의 중앙 통로로 달립니다. 끝의 빛 근처에서 E로 탈출합니다. 사건 기록과 마지막 편지를 모두 수집하면 기억 엔딩, 아니면 망각 엔딩입니다.

## 저장 동작

챕터 진입 시 안전한 체크포인트 좌표를 저장합니다. 이후 아이템/퍼즐 획득 때 진행 상태를 갱신합니다. 계속하기는 자유 저장 위치가 아니라 **마지막 챕터 체크포인트**에서 시작합니다. New Game은 기존 진행을 덮어씁니다. localStorage가 차단되면 알림을 표시하고 해당 세션은 계속 실행합니다. 설정 키는 `forest.settings`, 진행 키는 `forest.save`입니다.

## GitHub Pages

1. 이 프로젝트를 GitHub 저장소 `the-forgotten-forest`의 `main` 브랜치에 올립니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. 포함된 `.github/workflows/deploy.yml`이 의존성 설치, 단위 테스트, 빌드 후 `dist/`를 Pages에 배포합니다.

Vite `base: '/the-forgotten-forest/'`로 설정했습니다. 배포 주소는 `https://OWNER.github.io/the-forgotten-forest/`입니다. 개발 서버도 `http://localhost:5173/the-forgotten-forest/`로 접속할 수 있습니다.

이 환경에서는 Git 저장소와 유효한 GitHub 인증을 확인하지 못해 원격 업로드·게시를 하지 않았습니다. **iPhone에서 소스 ZIP을 올리고 배포하는 절차는 [DEPLOYMENT.md](DEPLOYMENT.md)**에 있습니다. 원래 게임 코드와 저장 키는 유지합니다. localStorage는 브라우저·출처별이므로 로컬 주소의 저장 데이터가 GitHub Pages로 자동 이전되지는 않으며, 기존 주소의 데이터는 그대로 남습니다.

## 검증

- `npm test`: 장애물 충돌/슬라이딩, 장애물을 우회하는 경로, 저장/설정/손상 데이터, 퍼즐 단서와 정답 일치 검증
- `npm run build`: 정적 배포 빌드
- `tests/pages.mjs`: `npm run preview` 실행 후 `node tests/pages.mjs`. 실제 빌드의 `/the-forgotten-forest/` 경로, JS/CSS 로딩, 개발 핸들 제외, 새로고침 시 저장·설정 유지와 CONTINUE 복원을 격리된 Chromium에서 검증합니다.
- `tests/browser.mjs`: Vite dev 서버 실행 후 `node tests/browser.mjs`. Playwright와 Chromium이 필요합니다. 이 환경에서는 `/usr/bin/chromium`을 사용하며 다른 환경에서는 경로를 변경하세요. 메뉴, 시작, 퍼즐, 챕터 전환, 두 엔딩, 저장 복원, 게임 오버와 재시작을 점검합니다.
- 브라우저 테스트는 개발 모드 `?test`에서만 노출되는 테스트 핸들로 위치와 수집 동작을 가속합니다. 사람이 처음부터 걸어서 완료하는 시간 측정이나 수동 조작 전체 검증을 대체하지 않습니다. 프로덕션 빌드는 이 핸들을 노출하지 않습니다.

## 알려진 제한사항

완주 가능한 소규모 게임으로, 상용 공포 게임 수준의 모델/애니메이션이나 포스트프로세싱은 아닙니다. 사진은 절차적으로 그린 추상적 조각이며 적은 기하학 실루엣입니다. 충돌과 AI는 지형의 수평면에서 계산하며 점프와 다층 건물은 없습니다. 동굴 끝은 바위 통로의 출구로 표현하며 별도의 낙하 절벽 플레이는 없습니다.

첫 플레이 15~25분 목표는 사용자 플레이테스트로 검증하지 않았으며, 길과 정답을 알면 훨씬 빨리 완료할 수 있습니다. 실제 GPU에서의 60FPS, 모바일/터치, Safari 및 Firefox 호환성은 아직 검증하지 않았습니다. FPS가 낮으면 그림자를 끄고 Low 및 해상도 스케일 0.5~0.8을 사용하세요. 브라우저 오디오 정책에 따라 클릭 전에는 소리가 나지 않습니다. 메뉴 글꼴은 Google Fonts를 선택적으로 로드하며, 오프라인에서는 시스템/Georgia 폴백으로 게임이 실행됩니다.

## 이번 환경에서 확인한 결과

- `node tests/core.test.js`: 4개 테스트 통과
- `npm test`: 테스트 파일 통과
- `npm run build`: 성공, 앱 약 37.6 kB + Three.js 약 487.2 kB (압축 전 JS)
- Chromium/Playwright: 메뉴 렌더, NEW GAME, 손전등/기록 수집, 챕터 2~5, 사진 정답, 암호 오답/정답, 두 엔딩, 새로고침 후 CONTINUE, 저장된 철문 상태, 게임 오버와 재시작 확인. 페이지 JavaScript 오류 0건
- `node tests/mechanics.mjs`: 15개 상호작용 지점 접근 가능, 적 추격/수색/복귀/소리 조사와 웅크리기 감지 감소, 걷기/달리기/웅크리기 속도 비교 통과
- 개발 테스트 핸들이 `dist/`에 포함되지 않음 확인

스크린샷은 `artifacts/menu.png`, `artifacts/game.png`, `artifacts/ending.png`에 있습니다. 테스트는 위치 이동과 일부 상호작용을 가속했으며, 전체 수동 완주나 실제 GPU 성능 테스트는 수행하지 않았습니다.
